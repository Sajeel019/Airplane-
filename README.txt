MY LOVE TAKES FLIGHT — WEBSITE

This is a complete single-file romantic website.
- First screen asks "Do you love me?"
- Tapping Yes changes to a night sky scene.
- An airplane flies while a glowing heart is drawn and smoke particles trail behind it.
- Includes replay and back buttons.
- No external assets or libraries are required.

To publish:
1. Open your GitHub repository named Airplane.
2. Upload/replace index.html with this file and commit changes.
3. Make sure GitHub Pages is set to branch main and folder /(root).
4. Open https://sajeel019.github.io/Airplane/ after deployment.
